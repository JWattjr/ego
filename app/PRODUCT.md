# Ego
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User-specified Next.js App Router, TypeScript, Tailwind; Vercel deployment, home-screen manifest.

## Product Purpose
Fun ways to move small amounts of USDC through map, code, event QR and puzzle drops on Arc. Launch city: Enugu, Nigeria.

## Capabilities and Constraints
The authoritative contract is ../INTERFACE.md. Seven flows; mock data must preserve its types and base units. API requests live in lib/api.ts. No wallet SDKs; TODO(wallet) marks integration. Exact spots appear only within 30 m. Location, orientation and camera access require explicit user interaction. Small drops, public places, daylight and location reporting are visible throughout the hunt.

## Brand Commitments
User specified clean, light, calm, premium, generous spacing and an original blue coin motif. No copied app visuals.

## Open Decisions
User confirmed wallet first. Mock wallet balances, creators and collectibles are illustrative, not live funds.
